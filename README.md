# AWS_PROJ

Detta repository innehåller ett experimentellt projekt med AWS. Projektet visar grundläggande användning av AWS-tjänster och hur man integrerar dem i backend-lösningar. Det är en bas som kan vidareutvecklas.

## 🛠 Funktioner
- Struktur för projekt med AWS-kopplingar  
- Grundläggande konfigurationsfiler för AWS-miljöer  
- Förberedelser för integration med AWS SDK/tjänster (ex. S3, Lambda osv.)
